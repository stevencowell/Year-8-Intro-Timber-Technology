How the course works

A steady routine every fortnight

Use the same calm learning rhythm in every paired-week module.

1. Learn

Read three focused theory sections and inspect the linked visual or original plan.

2. Check

Complete ten source-grounded questions for each named section. Retry from the exact theory heading.

3. Apply

Use the written response prompts to explain your own understanding and project decisions.

4. Review and save

Save locally, print your evidence or back it up through the folio.

Student evidence. Learning is browser-local practice, not a cloud submission. The folio can export one self-contained file for an intentional Google Classroom upload.
